# Wildlife map boundary data

`india-states-simplified.geojson` contains the 36 state and union territory
features used for the internal boundaries on the interactive map. It comes from
[Vardhan Maps](https://github.com/Vardhan-Systems/vardhan-maps), whose boundary
data is derived from OpenStreetMap and editorially adjusted. The data is
distributed under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Attribution: **© OpenStreetMap contributors**. See
`india-states-ATTRIBUTION.txt` for the data attribution and boundary-use notes.

The map data is a community-produced approximation, not an official or
survey-grade boundary source. Verify boundaries against authoritative sources
before legal, administrative, or research use. Wildlife example markers are
illustrative and are not confirmed sightings or species-range records.
